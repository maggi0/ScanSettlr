# ScanSettlr

Aplikacja mobilna do zarządzania grupowymi płatnościami, umożliwiająca rejestrowanie wydatków, podział kosztów oraz automatyczne rozliczanie użytkowników.

## Technologie

- .NET MAUI – aplikacja mobilna
- Java / Spring Boot – backend REST API
- MongoDB – baza danych
- Docker Compose – uruchamianie usług
- PaddleOCR – rozpoznawanie tekstu z paragonów
- Ollama / Mistral – przetwarzanie danych z OCR
